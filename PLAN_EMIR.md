## API эндпоинты которые Эмир использует

| Эндпоинт | Метод | Что делает |
|-----------|-------|-----------|
| `/auth/login` | POST | Авторизация, получение JWT |
| `/auth/register` | POST | Регистрация |
| `/hotels` | POST | Создание отеля (визард) |
| `/hotels/{id}` | GET | Данные отеля |
| `/hotels/{id}/configure-channels` | POST | Подключение TG/WA |
| `/preview-chat/simulate` | POST | Демо-чат (JWT) |
| `/conversations/` | GET | Список диалогов |
| `/conversations/{id}` | GET | Диалог с сообщениями |
| `/admin/hotels/` | GET | Список отелей (admin) |
| `/admin/hotels/{id}/budget` | GET/PUT | Бюджет |
| `/reports/hotel/{id}/monthly` | GET | ROI-отчёт |
| `/share/` | POST | Создать share-link |
| `/share/{token}` | GET | Получить shared данные |

Все вызовы через `lib/api.ts` с JWT Bearer авторизацией.
